【题材】都市异能悬疑系统流（番茄向热门：底层职业 + 危险预感异能 + 专营"完美意外"的隐藏组织）

【主角】周野，26 岁，写字楼里的外包程序员，正被裁员边缘。一次连续高烧三天后，他眼前出现一种只有他能看到的「危险倒计时」：任何将死之人头顶会浮现倒计时，倒计时归零即死亡。

【能力规则】
1. 倒计时只出现在"将死之人"头顶，精确到分钟。
2. 周野看不到自己的倒计时。
3. 第一次出现：他下班路上目睹一场车祸，肇事车里坐着的乘客头顶有 3 分钟倒计时——而那个人没有受伤，他在等着别人死。
4. 倒计时可以被"改写"：某些人能让倒计时归零的方式变得"意外"，这意味着有人在操纵死亡。

【核心卖点】信息差 + 倒计时逻辑推理。爽点：倒计时不是预言，是线索——周野一次次在倒计时归零前赶到现场，发现每一起"意外"背后都是同一个组织在制造死亡。对手不知道有人能看见倒计时。

【冲突主线】
1. 能力来源成谜：高烧三天醒来后出现；住院那晚隔壁床的病人病历写着「倒计时综合征」——那是第一例记录。
2. 隐藏组织「殡仪馆」：专营"意外死亡"的灰色生意，能用某种技术改写倒计时，让谋杀看起来像意外。
3. 代价：每次救下倒计时者，周野会失去一小段记忆（他逐渐记不起高中之前的事）。

【第一卷方向】发现车祸异常 → 追踪第一起被改写的"意外" → 撞破殡仪馆的业务员 → 得知组织存在；与警方法医苏遥（她也在查连环意外案）形成亦敌亦友关系；房东陈叔（知情者）逐步揭示能力的前任拥有者。

【约束】不虐主；反派不降智；能力规则明确（只看将死之人、看不到自己、救人失忆代价累积）；终局信息前期不出现；重大揭示需至少两层铺垫；不能频繁依赖巧合。
