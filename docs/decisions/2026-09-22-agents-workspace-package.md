# Agent 独立工作区包

## 问题与决定

Agent 需要独立管理依赖和构建入口，供小说业务及工作流通过公共接口使用。将 `src/agents/` 登记为私有 pnpm 工作区包 `@fly-novel/agents`，根项目通过 `workspace:*` 引用。Deep Agents 与 LangChain 依赖归属该包，现有版本约束保持不变。

## 影响

包与应用保持 CommonJS，TypeScript 使用 NodeNext 解析公共导出。编辑器通过源码映射免构建检查；应用正式构建使用包产物，显式先构建包。包入口不执行模型调用；初始示例保留在包说明中。四类业务模板不属于此次包拆分范围。编译配置继承根配置，独立包不等于独立仓库或已具备公开发布配置。

## 验证

验证工作区安装、类型检查、包和应用构建、声明入口以及通过包名加载的无凭据冒烟检查。根测试入口因编译配置调整进行回归验证。具体使用说明见[包 README](../../src/agents/README.md)。
