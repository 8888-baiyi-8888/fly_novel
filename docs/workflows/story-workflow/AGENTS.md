# 故事级工作流目录说明

## 仓库结构

- `story-workflow.md`：故事级工作流的整体流程、主要机制和待确定问题。
- `story-workflow-development-plan.md`：故事级工作流分阶段开发目标、依赖和验收。
- `story-workflow-stage-1-director-plan.md`：基础导演 Agent 的详细开发步骤与验收。
- `story-workflow-stage-2-director-delegation-plan.md`：父子导演委派的详细开发步骤与验收。
- `story-workflow-stage-3-records-plan.md`：故事、场景和运行记录的分步开发与验收。
- `story-workflow-stage-4-world-materials-plan.md`：世界资料接入、场景缺口核查及按需补充的分步开发与验收。
- `story-workflow-stage-5-character-participation-plan.md`：场景参与请求、逐角色认知、角色调用及参与记录的分步开发与验收。
- `story-workflow-stage-6-scene-interaction-plan.md`：场景事件、逐角色感知、回合调度、行动判断与场景结算的分步开发与验收。
