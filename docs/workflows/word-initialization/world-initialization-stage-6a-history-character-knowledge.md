# 历史设定与角色认知边界

历史事件保存世界层面的公开说法、隐藏内容和未知；角色初始化资料保存该角色当时已知或误认的内容。角色可以认为战争由天灾引起，而历史资料保存商会推动战争的设定；两者不自动同步，也不因为历史更新而覆盖角色原有认知。

角色之后如何通过亲历、交流或调查形成记忆和改变认知，属于后续世界运行与角色认知机制。历史事件不维护角色知情名单，不预设角色会发现什么，也不以组织权限等级或历史 Agent 的完整视图代替角色实际经历。

当前角色 Agent 是样例，没有根据角色 ID 自动加载长期认知；历史工具面向规划者并可返回完整事件。角色运行装配未提供完整的角色认知读取边界或文件、搜索和目录旁路隔离，因此不能将历史文件或完整历史工具直接作为故事角色的认知输入，也不能声称现有角色已经受到完整隔离。

现实目录验证见[角色认知边界测试](../../../src/app/tests/history-character-knowledge.test.ts)：分别保存两位角色的不同认知，更新世界历史，检查角色文件保持原样，并验证事件格式拒绝角色知情名单。测试不模拟故事演化或模型自主认知。
