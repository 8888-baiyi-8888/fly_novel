# 第 8 阶段验证与第 9 阶段交接

本文记录影响检查、审阅选择和受控发布的验证范围及恢复边界。业务格式与应用装配见[世界初始化模块说明](../../../src/world-init/README.md)，阶段目标与验收见[第 8 阶段计划](world-initialization-stage-8-impact-review-plan.md)。

## 已验证的行为

- [固定模型替身集成测试](../../../src/app/tests/world-review-e2e.test.ts)使用两个真实临时世界，覆盖同名地点隔离、模型声称确认但没有可信用户动作、重要冲突、显式选择、确认后采用已展示建议、检查范围变化和取消。它只证明脚本执行的路径，不证明真实模型的分析质量。
- [逐项发布测试](../../../src/world-init/tests/commit-service.test.ts)覆盖地点已发布、人物失败、文件未开始，用户核查后重新检查和确认；还覆盖取消、结果不确定、人物索引故障、目录过期或损坏以及后续正文变化。目录检查结果与正文发布结果分别保留。
- [进程中断测试](../../../src/world-init/tests/batch-process-recovery.test.ts)让子进程在正文发布后退出，重新打开服务，按实际文件版本和模拟用户的明确选择恢复候选。此测试不证明断电后的持久性，也不证明跨进程锁。
- [模块候选测试](../../../src/world-init/tests/discussion-service.test.ts)和[扩展模块测试](../../../src/world-init/tests/discussion-extended.test.ts)通过真实文件覆盖组织及成员、人物关系、历史、局势、规划、专有内容和文件的版本保护、状态保留及发布；新增目标、删除目标和新增人物关系条目仍不支持。
- 相关集成测试运行 19 项，其中 18 项通过、真实模型测试按默认开关跳过；正式构建和类型检查通过。局限于受测平台及测试路径，不等于全量或跨平台验证。

## 真实模型样例

[隔离真实模型测试](../../../src/app/tests/world-review-real.test.ts)准备地点、讨论、影响报告、审阅与逐项发布；确认动作由测试代码模拟，不能称为人工审阅。默认关闭真实模型调用。

受限环境中的一次运行返回 `fetch failed`，联网重试在明确授权发送范围前被自动审批拒绝。取得用户对 DeepSeek 端点和合成测试内容的明确授权后，两次隔离真实模型运行均通过：模型保存了城门候选、调用影响检查，并区分已检查和未覆盖范围；测试核对了候选只改变描述字段，以及发布正文与候选全文一致。模型请求使用临时合成世界，并包含应用提示词、工具定义及可能出现的本地工作区路径。

样例中的确认由测试代码模拟，未进行人工语义审阅；两次通过只说明这两个运行样例的行为，不证明对其他世界的冲突判断或生成质量。报告、候选和 Session 留在被 Git 忽略的隔离测试目录中，不能视为用户世界的交付成果。

## DeepSeek Harness 对照

对照固定提交 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159` 的[工具注册与执行](https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/packages/core/tools/README.md)、[文件工具](https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/packages/fs/tool-fs/README.md)、[本机文件后端](https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/packages/fs/fs-local/README.md)及 [Session 持久化](https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/packages/session/session-persistence/README.md)：上游提供工具声明与权限、可选读取观察、文件版本保护和 Session 事件持久化。本项目沿用工具和作用域的能力边界，在可信应用另行保存业务审阅、用户选择及逐项发布记录；讨论 Agent 不获得发布工具。上游 Session 的持久化边界不能直接证明世界资料已确认或多文件发布完成。本项目世界协调器仅覆盖已接入的同进程入口，不能从上游文件原子写入推断跨文件事务。

## 第 9 阶段需要接收的状态

当前正文、讨论 Session、候选、影响报告、审阅、确认和发布记录分别读取。版本 1 活动 / 放弃候选与版本 2 发布中 / 已提交候选须按各自格式处理；未知版本或损坏文件保留并拒绝。批次中的已提交、未开始、发布中及目录状态须逐项呈现，不从 Session 或单个成功文件推断整个初始化完成。

世界协调依赖已接入的本机后端和单可信写入进程；外部进程、硬链接、本机并发路径替换及未接入入口不在保证范围。目录可能未配置、未登记、过期或检查失败，不自动生成简介。影响查询只覆盖报告列出的关联，未覆盖范围需要明确知悉；语义冲突仍需由应用和用户判断。

第 9 阶段还需组装可供真实用户使用的完整初始化入口、统一恢复编排与最终交付，解决未覆盖查询及失败后的人工处理，不应把固定替身测试或局部提交视为整个世界初始化完成。
