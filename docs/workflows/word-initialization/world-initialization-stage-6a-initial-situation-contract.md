# 初始局势资料契约

本文定义[初始局势计划](world-initialization-stage-6a-initial-situation-plan.md)的版本 1 文件边界；实际存储入口见[局势包](../../../src/agents/plugins/initial-situation/README.md)。

一个世界在负责人目录的 `start.json` 独占保存初始化起点说明；初始化期间可按读取版本更新，调用方须先检查已有历史相对时间等影响，不能静默视为已经换算。说明可表达未知或世界内纪年，不将文件时间当作世界时间；现有历史时间格式不会自动读取或换算该文件。起点确认后的修改和自动影响检查留给后续明确设计。

每个方案在 `overviews/<方案ID>.json` 保存名称、概况、覆盖和留白；每项局势在 `situations/<局势ID>.json` 保存所属方案、名称、展开程度、概况、正文、引用、关联和留白。条目只属于一个方案，条目关联只指向同方案内已存在的条目；反向查询不等于反向因果。不同方案各自保存正文，可引用同一个地图、组织等权威资料；修改一个方案不会覆盖另一个。

文件使用程序生成的 UUID，名称与 ID 分离并允许重名。文件内包含 `formatVersion: 1` 和可信世界 ID；总览和条目包含 `suggested` 或 `confirmed` 审核状态。创建均为待审，不提供选择方案或确认入口。JSON 额外字段、重复键、未知版本、身份不符和损坏文件拒绝读取并保留原文件；旧 Markdown 或其他模块文件不自动迁移、覆盖或删除。

关联引用按类型和 ID 指向已建档历史、地点、组织、组织关系、人物或人物关系；未建档对象和基础信息可保存明确的文字线索。引用说明可包含记录时读到的来源版本，但版本不是世界时间；显式引用核验按可信解析器返回的实际版本比较，区分未配置、未找到、未知、变化和未变化。无解析器的已关联引用拒绝写入；解析器失败不等于对象不存在。模型提供的记录版本不是系统对原始读取的证明。名称不能作为身份，引用不自动意味着因果、成员或知情。

未确认的方案或条目按读取版本完整更新，版本冲突拒绝；已经确认的资料只能创建一份待审候选，保存基线并在读取时报告是否过期，候选不覆盖正文。已有候选时禁止直接更新。当前没有候选提交、世界演化留存、跨文件事务或自动选择方案；创建和目录登记分别进行，结果不确定时先核实实际文件。存储的单进程占用不提供跨进程锁或系统级隔离。
