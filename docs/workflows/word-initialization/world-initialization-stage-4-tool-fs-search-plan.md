# 文件能力第八包：文件搜索工具开发计划

本计划细化[第四阶段第 8 项](world-initialization-stage-4-file-tools-plan.md#8-dsh-tool-fs-search文件搜索工具)，以受控 ripgrep 执行路径提供 `glob` 和 `grep`，并与文件读取使用同一可信授权视图。按步骤验证和提交后自动继续；未经验证的隔离能力不用于生产装配。

## 来源和边界

依据用户提供的 DeepSeek Harness 官方下载快照 `packages/fs/tool-fs-search`，版本 `0.2.2-rc.1`，MIT 许可证，未核验 Git 提交标识。`src/index.ts`、`src/glob.ts`、`src/grep.ts` 和 `src/search-core.ts` 的 SHA-256 分别为 `5193d396dcc769e5e79b5a9a3bdbd81a6709df6988d7e3fffa020add75b401b5`、`ba59f2702d828d6dfc0ff27b73897d938ae3c6a9c06e4616cdafb07bc90f1e2b`、`797505064759c7dd49052a7fa56165c04021d2b12ff2993d0c31604a004d84d0`、`d642c99286faff7cb6e70a24b0c4743184b3f83e8c6620bc9537c426987b198f`；实际移植其他源码时补充哈希。

上游使用 `@vscode/ripgrep`、无 Shell 的固定 argv、`--no-config`、原始输出上限和取消信号；`glob` 列出文件，`grep` 解析 `--json` 匹配记录。上游不使用文件后端校验搜索根，明确要求工作目录和读取视图一致，因此不能直接将其视作本项目授权方案。本项目子进程回退后端不构成内核隔离，见[子进程计划](world-initialization-stage-4-subprocess-plan.md)。

## 1. 核对依赖与搜索授权

逐项核对上游 schema、argv、错误、超时、结果裁剪和实际运行依赖，检查 ripgrep 包版本、许可证、平台二进制及构建安装方式。梳理可信工作目录、文件后端解析、搜索目标和结果路径的映射；对绝对路径、父目录、目录链接、显式文件链接、路径重定向、错误输出及并发替换进行威胁分析。确定不跟随目录链接及对结果逐项验证的可执行方案，不假设进程 cwd 是授权沙箱。

**验收**：来源、实际依赖与授权数据流可追溯；无法通过路径检查避免的并发窗口和进程后端限制有明确说明。

## 2. 包及受控搜索执行

引入并固定实际使用的 `@vscode/ripgrep`，建立独立工作区包及显式插件，适配项目 Tools、文件后端、期限和子进程服务。由可信调用方提供读取根，解析模型搜索目标并拒绝越界；只执行包内可信二进制和固定参数模板，使用 `--no-config`，模型参数作为独立 argv 元素，路径置于 `--` 后。适配上游退出码、错误、输出溢出与取消语义，不传递未授权的 stderr 路径或内容。

**验收**：包独立构建、注册和清理；启动失败、无结果、非零退出、取消、期限和原始输出溢出行为可验证。

## 3. glob 与 grep

移植上游路径匹配、正则搜索、JSON 解析和有限结果格式，配置上限在入口校验；明确忽略文件、隐藏文件、VCS 目录及符号链接的实际行为。对每条待返回路径重新验证读取授权，结果需可在同一视图读取；不使用未经授权的 spill 文件保存结果。覆盖常规匹配、无结果、截断、非法模式、非 UTF-8、输入前导横线、特殊路径及路径越界。

**验收**：真实工具服务返回有界、可解释的路径与内容；范围外路径或内容不进入模型结果，错误不泄露范围外信息。

## 4. 集成与交付

用固定模型替身和真实 Loop 验证搜索结果可读取，两个 Agent 的读取视图隔离，覆盖取消、超时、作用域销毁和并发路径替换的受控用例；检查冻结安装、构建、类型、公开入口、许可证、链接和空白。记录实际平台和跳过项；文件读取与搜索的检查到系统调用之间仍有并发替换窗口，生产装配在第 9 项复核。

**验收**：项目真实执行链、读取视图和进程生命周期有证据；未验证的系统级隔离不得宣称通过。
