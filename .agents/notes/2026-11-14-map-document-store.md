# 地图 JSON 格式与受控存储

- 问题：地图文档需保留多父级范围，拒绝损坏或错误版本，并安全地创建地点和更新连通设定。
- 决定：新增独立 `@fly-novel/map` 工作区包，复用文件服务、`yaml` 重复键检查和 `zod`；以可信根、世界和只读 / 读写模式绑定 `MapStore`，使用独占创建与连通版本保护。
- 影响：存储在同一进程串行并限制世界和目录占用；调用方准备目录、持有文件后端并确保单可信写入进程。地图查询、几何计算、模型工具及 Cordis 服务留待后续，文件写入异常的结果不确定时提供路径供核查。
- 验证：使用实际本机文件后端验证多父级、重复键、未知版本、无效坐标、自引用、错误世界、环、连通更新与冲突、只读、取消、清理及发布结果不确定。Windows 当前环境不能创建文件符号链接，使用真实目录联接验证文档路径的链接拒绝；文件符号链接本身未在该环境实测。
