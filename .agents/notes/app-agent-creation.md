# 应用层 Agent 创建与批量注册

## 问题

应用需要分别提供各类 Agent 的创建入口，并通过列表注册工具。

## 决定

src/app/agents 下各创建函数自行读取本机模型配置，通过既有 AgentFactory 创建独立实例；调用方通过实例 dispose 释放资源。各 Agent 在自己的创建文件中维护工具列表，逐项注册失败时记录错误并继续。角色、导演和写作 Agent 工具列表为空，添加工具前须在对应 Preset 装配 tools 服务。通用 registerAll 保持失败即停止语义。

## 影响与验证

各入口可独立初始化并清理。固定模型测试覆盖不同 Preset 的创建和实例隔离；世界初始化工具失败测试覆盖日志及继续运行，通用工具服务的失败语义保持不变。
