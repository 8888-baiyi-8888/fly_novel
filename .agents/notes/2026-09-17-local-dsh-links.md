# 学习阶段链接本地 DSH

问题：从 npm 安装投影服务时，其依赖链中的包返回 404。用户提供同级 deepseek-harness 仓库用于学习。

决定：通过 link: 引用本地投影、Session 和 Agent 包，使用原仓库已有的 lib 与依赖链接；Zod 复用投影包安装的版本。外部类型与 Zod 转导出集中在 session/dependencies.ts。未复制或修改上游源码。

限制：两个仓库的位置、上游依赖安装和构建产物均为运行前提。本地会话与 LLM 类型尚不能视为和上游协议兼容，不能通过类型断言隐藏差异。

验证：离线安装链接成功，四个依赖可从 Harness 包目录加载。Harness 草稿仍需完成自身类型与生命周期实现；包可解析不表示整体框架可以运行。
