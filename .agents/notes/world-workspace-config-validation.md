# 多世界工作区配置校验

问题：现有世界初始化入口只能描述单个读取视图与主 Agent 草稿目录，不能检查多个世界及多个持续身份的目录关系。

决定：可信应用以集合提供世界、主 Agent 和特殊 Agent 的稳定身份及已有真实目录；在不修改用户数据的前提下检查身份唯一、世界根互不重叠及世界内受保护根和专属根互不重叠，并返回冻结快照。

影响：校验只覆盖传入集合，不提供跨进程锁或抵御本机恶意并发替换、硬链接；现有 Agent 创建入口未接入新配置，工具权限和生命周期仍由后续步骤装配。

验证：使用双世界、多身份夹具和冲突、越界、缺失、符号链接及平台大小写用例，检查原文件保留；运行相关测试及类型检查。
