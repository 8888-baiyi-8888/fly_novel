# 世界初始化文件工作区边界

问题：上游文件沙箱的 workspace-write 包含系统临时根，仅配置草稿根不能阻止修改临时目录中的已确认资料。

决定：可信应用显式提供现有读取视图、草稿根和已确认根，创建 Agent 前按真实目录身份检查包含和重叠，并拒绝已确认根与任意上游可写根相交。主 Agent 另外限制修改到草稿根，子 Agent 使用只读策略。

影响：不会自动创建目录或推断确认状态；路径检查不构成抵御恶意本地进程或硬链接的内核隔离。世界资料业务模型与确认流程仍由后续阶段建立。

验证：配置测试覆盖根目录关系、缺失路径、目录链接及系统临时根；草稿后端和真实主子链路在后续装配步骤验证。

委派工具的 Preset 由可信装配配置，缺省保持 generic-subagent；专用子 Agent 使用独立注册的只读 Preset 和独立 Session，模型不能通过任务参数选择或扩大权限。

Skill 来源由应用对内置 Skill 目录单独授权，不将该目录加入文件工具读取视图；Skill 资源如需通过文件工具读取，仍须位于该视图。

受控工作区为主、子 Agent 分别注册提示词段，说明当前真实读取根、草稿和已确认资料的相对路径及各自权限。该说明由可信配置生成并随作用域注销，文件后端仍负责实际授权。
