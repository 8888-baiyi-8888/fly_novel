# Skill 工具最小加载

问题：需要在开发 Skill 注册表和 Agent 授权前，验证工具能够加载世界初始化主 Agent 的 Skill 样例。

决定：提供由可信调用方绑定绝对目录的文件系统来源和 skill 工具；仅支持授权工作目录内的名称目录及 SKILL.md。元信息使用 yaml 解析，模型调用权限和真实路径在加载时检查。

影响：工具通过现有 Tools 服务执行，不改变 Session 格式；目录发布、完整提供方注册和 Agent 绑定留待后续步骤。授权目录必须防止不可信进程并发替换路径。

验证：类型检查、测试编译、Skill 工具聚焦测试、正式构建及构建产物加载样例的冒烟检查。
