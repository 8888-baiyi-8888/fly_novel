# 宏观发展蓝图规划

问题：同一世界可能有多个候选初始局势及不同未来方向，现有局势方案尚无确认选用流程。

决定：按用户确认，一个世界的宏观蓝图包含多个方向，方向可分别关联不同待审局势方案；宏观蓝图、故事线和人物成长蓝图由同一个世界发展规划 Agent 负责，并联合规划开发。成长线维护人物详细成长方向、阶段与可能转折，成长蓝图负责跨人物成长重点、相互影响及与世界发展的呼应，并引用成长线。

影响：三类内容保持独立归属，联合计划统一处理 Agent、存储和关联；不把候选局势当作同时成立，也不实现世界推进或决定角色行为。存储、工具和具体关联契约属于待实施方案。

验证：检查详细计划的现有能力依据、局势方案例子和相关文档链接。
