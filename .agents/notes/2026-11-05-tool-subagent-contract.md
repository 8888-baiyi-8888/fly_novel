# Tool SubAgent 首版契约设计

## 问题

通用和角色委派工具需要复用 Spawn，同时为每次角色委派提供独立的角色 ID；当前角色 ID 无法进入子实例插件作用域。

## 决定

计划以两个作用域工具分别委派 generic-subagent 和 character-agent，首版前台等待并释放运行。角色 ID 经每次请求输入与可信创建校验进入子实例只读输入，由角色绑定组件读取；该绑定不加载档案，也不表示角色存在。通用 Agent 使用独立 Preset 和角色类型。通用工具属于 tool-subagent 包，角色专用工具属于 src/tools，由可信装配分别注册。

## 影响与验证

这是一份待实施设计；实现时检查公开请求、Agent 创建与作用域注入、可信装配、Provider 兼容、取消和资源释放，并验证双重错误的内部保留与工具结果投影。
