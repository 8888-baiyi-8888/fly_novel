# CharacterAgent 结构化输出

日期：2026-09-24

问题：输出字段仅拼接到提示词，没有 Schema 约束；角色实例又需要支持逐轮切换字段并延续记忆。

决定：使用 Zod 严格对象和 Deep Agents responseFormat/toolStrategy。模型调用中间件逐轮替换格式配置，复用框架实例和检查点。选择在模型初始化前校验，框架完成工具格式解析后，返回边界再次校验 structuredResponse，拒绝缺失结果及额外字段。每轮清空旧 structuredResponse，防止沿用上一轮成功结果。解析失败不自动重试。

范围：基础表现和内心活动为字符串，状态变化为目标、变化、原因及依据列表；不是 F4/F5 的完整表现项及可执行更新协议。人物一致性与正式状态提交仍未实现。既有记忆工具和文件持久化保留。样例打印结构化结果。

验证：15 项聚焦测试通过，包含逐轮切换字段且历史保留、缺失/错误/额外字段拒绝、缺失本轮结果不复用旧值、无效选择提前拒绝，以及既有记忆文件和并发验证。测试使用模型替身，未调用真实模型。历史条数断言改为检查用户轮数，因为框架结构化响应会增加工具消息。
