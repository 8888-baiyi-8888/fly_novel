# LLM 未提交实现的职责整理

## 问题

新增入口混合适配器、错误与运行时实现，附件类型重复，注释包含英文及未接入的上游模块说明。源码导入扩展名不统一，编译配置无法生成正式产物；运行时缺少注册方法、模态复制方法及 Cordis 事件声明。

## 决定

入口仅汇总导出，适配器、运行时、错误分别维护；附件类型统一到 types.ts，通用冻结函数使用明确的 deep-freeze.ts 文件名。相对导入遵循现有 CommonJS 无扩展名约定，删除不适用于正式构建的 allowImportingTsExtensions。注释改为中文，并将尚未接入的能力在模块 README 中明确列出。

补齐现有流式分发需要的路由注册和幂等注销；拒绝重复注册且批量失败不留下部分结果。校验图片卸载数量；流终止、提前退出和迭代失败时关闭迭代器；附件读取仅降级明确的缺失错误。

## 影响

LLM 继续独立于 Harness 和应用配置。已有 DeepSeek 非流式入口保持不变；不新增供应商、自动重试或附件存储实现。新增测试位于 src/llm/tests，不进入正式构建。

## 验证

类型检查、构建以及 LLM 聚焦测试覆盖注册清理、默认参数、流式失败与取消、中间件边界、内容投影、深度冻结和失败信息校验；构建后验证公共入口可以加载。
