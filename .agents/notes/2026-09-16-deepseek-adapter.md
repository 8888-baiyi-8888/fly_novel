# DeepSeek 接入统一适配器

## 问题

DeepSeek 原先通过独立函数请求，未使用已有 LlmAdapter 和 LlmRuntime 的统一消息、路由与失败协议。

## 决定

以 DeepSeekAdapter 替换独立函数，实现 LlmAdapter.stream。构造参数只包含连接信息和供应商思考模式，模型请求使用 GenerateOptions。保持 HTTP 非流式请求，完整响应校验后转换为统一内容块、用量和结束原因，不加入 SSE 或自动重试。

## 影响

app 继续按需读取配置和解密，通过运行时注册、调用和注销适配器；文本便捷入口使用统一消息并只聚合文本。公共入口导出 DeepSeekAdapter，旧函数不保留兼容层。错误不包含供应商响应正文；取消信号传到网络请求。测试响应补齐供应商必需的 finish_reason 字段。

## 验证

模拟 HTTP 响应验证请求映射、文本与推理块、工具调用、缓存用量、结束原因、HTTP 错误、非法响应及取消；运行类型检查、构建、测试及差异空白检查。不使用真实凭据访问服务。
