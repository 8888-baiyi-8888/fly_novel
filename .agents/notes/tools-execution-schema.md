# 工具执行与 schema 校验

问题：执行工具需要验证模型参数和规范输出，并将结果关联原始调用。

决定：参照固定版本的 DeepSeek Harness schema 编译与校验代码，ToolsService 接收单项原始调用，解析参数、执行工具并校验输出；返回调用 ID、规范值、模型内容或结构化错误。授权目录由本项目调用方提供。

影响：调用者需要提供取消信号和工作目录；批量调度、官方作用域执行器与 Session 记录属于后续步骤。上游源码和移植调整见 src/agents/plugins/tools/README.md。

验证：工具执行测试覆盖嵌套 schema、无效参数、无效输出、未知工具和取消；文件读取测试验证实际服务调用。
