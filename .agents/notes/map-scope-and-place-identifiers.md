# 地图范围与地点标识

真实模型样例中，主 Agent 在限定近期只规划曲水城的任务上额外委派了周边地点，并要求生成另一套城市标识。地图工具实际生成的 UUID 与组织结构化地点引用一致，但自由文本中出现了未经核验的 `city.qushui`。

主 Agent 委派时应传递用户明确的范围，必要的父级概况仍可建立；没有范围限制时按世界需要规划。地点正式 ID 以地图工具返回或读取结果为准，其他模块引用时使用该 ID，不另造正式标识。自由文本的语义无法由结构化字段格式校验保证；既有样例不自动修改。

通过主 Agent、地图和组织的提示及工具说明表达上述约束，并测试结构化引用拒绝非 UUID。独立地图 Agent 的真实模型测试覆盖单地点限制与正式 ID，不代表主 Agent 的真实委派已通过端到端验证。
