# 组织查询与工具绑定

组织成员由组织模块维护，同一世界中的规划者和角色需要不同的读取范围。组织查询通过可信应用绑定角色及其按组织分配的授权，过滤后才计算分页；关系要求两端权限均满足，角色结果不返回原始路径和文件版本。授权来源与其他读取工具的隔离由应用负责，组织插件不宣称实现系统级隔离。

跨模块引用复用应用持有的地图和人物存储，并校验其世界和根目录，避免再次打开被占用的地图存储。引用核验不自动维护外部资料，也不代替角色授权。组织 Agent 与世界演化历史继续由后续步骤实现。

验证覆盖角色等级、授权变化、隐藏资料、关系及成员查询、工具身份、引用解析与跨世界拒绝；运行命令和结果以交付说明为准。
