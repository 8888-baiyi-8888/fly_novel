# 统一故事运行的恢复依据

第十阶段计划复用业务模块各自的权威记录，以运行入口记录关联配置、规划与操作身份。只读诊断与显式推进分开，统一入口复核各模块记录并定位下一步，无需复制场景、事件或状态正文。恢复只重复能够证实未发生业务效果的操作，或补齐已有结果缺失的引用。

排期结算与父子故事继续分别核对原领取证据。角色运行器可按可见证据重新装配，私有 Session 沿用既有角色边界。曲水城夹具在审阅、场景互动和状态应用后中断，覆盖新进程继续与保留待核查两种情况。

## 入口核查

| 保存点 | 当前凭据及缺口 |
| --- | --- |
| 规划 | 独占规划文件可按 ID 重读；现有随机 ID 在模型返回后分配，开始请求丢失响应时缺少关联。 |
| 父子推进 | 批次独占消费。树中保存子项决定、任务、拆分、补充、模拟、报告和评估；缺少批次时，现有只读核查会报告当前位置，但不会从部分已完成子树重建推进。 |
| 场景与角色 | 场景结果绑定互动结束状态。发言、判断、调度领取和有效响应可分别重读。只有参与领取时不能推断响应结果；只有部分场景时不能推断整个模拟结束。 |
| 排期 | 已领取场景可用现存已结算场景和状态回执核对，已领取且证据不全时不能重放。继续互动需要明确接管同一领取和回合。 |
| 事件与状态 | 已采用事件和商队预期版本、操作 ID 及真实回执可独立核对。发起应用前的意图与模拟结束需要由可信应用保存，供中断后定位。 |

沿原有故事入口、调试入口、批次恢复、场景读取、角色参与、调度及初始化交付契约核查。验收以曲水城持久夹具和受控中断验证。
