# 讨论记录与首批候选

问题：现有角色候选没有讨论归属和条件更新，地点没有候选；当前方案无论确认状态都必须保留。

决定：隔离目录内使用版本 1 讨论和候选记录，按目标独占、按候选版本条件更新；保留放弃记录并拒绝接管旧人物候选。地图模块校验候选父级图，人物沿用自身文档格式。主 Agent 工具由可信应用绑定讨论、世界和 Session。

影响：候选保存不提交当前资料；首批只支持已有地点和人物，其他目标及新增删除需后续步骤。文件结果不确定时保留可核查标识，单可信进程内串行处理，不提供跨文件事务或跨进程锁。

验证：真实地图、人物与候选目录测试，覆盖独占、并发版本、重启、过期、旧候选、未知格式和发布结果不确定；固定模型工具测试验证主 Agent 只能使用绑定目标且不覆盖当前正文。
