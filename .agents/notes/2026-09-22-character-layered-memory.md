# 角色分层记忆与线索唤回

## 问题

全量加载历史会挤占当前互动上下文，只有统一摘要又会丢失近期原话与未完成动作。久远经历需要在相关线索出现时恢复可用，而不是被物理删除。

## 决定

在[角色详细设计](../../docs/modules/agents/character-agent.md)中定义近期完整记录、较远相关摘要及沉寂记忆。运行输入通过 `recent`、`summaries`、`recalled` 分组提供，应用维护派生摘要与索引，原始事件保留。重要未决事项不因时间降层而消失，线索检索受人物与剧情版本限制。

## 影响

保持工厂、运行和采用流程。应用负责材料预算、摘要准备及运行前唤回，角色可通过注入的查询能力补充历史。沉寂不删除事件，唤回不自动改变性格，不引入概率遗忘或向量数据库要求。

## 验证

文档检查覆盖结构、链接、JSON 示例与空白；设计规定完整近期互动、摘要忠实度、重要承诺保留、线索查询、超预算拒绝及版本隔离验收。本次只更新文档，未实现或运行这些行为测试。
