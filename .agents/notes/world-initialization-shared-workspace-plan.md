# 世界初始化共享工作区方向

问题：主、子 Agent 需要共享读取世界资料，同时避免互相改写工作成果，并能发现资料目录中的简介已经过期。

决定：一个世界使用共享读取工作区，各 Agent 仅修改自己的目录；特殊子 Agent 由用户决定，持续身份与可重新创建的运行实例分开。成果在实例销毁后保留。资料目录通过专用工具维护简介和文件版本，发现过期后由主 Agent 委派负责者更新。优先复用 Agent 配置及目录约定，不预建独立映射系统。

影响：跨 Agent 修改、已确认资料及目录文件的保护须由程序执行；登记权限、目录格式、版本机制、并发实例处理和对齐时机在实施前确认。现有记忆模块尚未实现，重新实例化不等于恢复记忆。

验证：第五阶段详细计划列出授权、并发、版本竞争、世界隔离、实例重建与失败处理的验收步骤；本次仅制定计划。
