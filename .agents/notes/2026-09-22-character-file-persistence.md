# 角色资料与记忆的文件持久化

## 问题

人物状态与记忆需要在进程退出后保留，分别覆盖多个正式文件可能造成只保存行为却丢失同轮心理变化。

## 决定

[角色详细设计](../../docs/modules/agents/character-agent.md)增加 F9，以不可变单轮提交文件同时保存经历和更新后快照，摘要与索引作为可重建缓存。程序负责目录约束、格式校验、串行写入、版本检查与原子发布；角色模型不直接编辑文件。

## 影响

保留现有角色调用和业务提交职责，新增应用启动恢复与退出释放要求。首版封装格式版本为 1，未知版本拒绝读取，原始数据不自动删除。事务范围限定单人物单分支，不承诺跨人物事务或未经验证的断电耐久性。

## 验证

本次检查文档链接、结构、JSON 示例与空白。设计列出重启、写入中断、重复提交、冲突、损坏、未知格式、缓存重建和路径约束等文件集成验收；本次未实现文件存储或运行对应测试。
