# 初始化最终审阅与交付

- 问题：当前正文、待审候选和 Session 分别变化，仅凭目录或一次确认无法重建用户实际接受的世界。
- 决定：独立版本 1 审阅和交付记录保留所选正文与业务发现快照；完成前在同一协调边界重新核对范围、第一版、候选、正文、报告和发布记录，并要求逐项确认暂留与未覆盖范围。
- 影响：不自动提交或放弃候选，不改写模块确认状态；重要冲突无法证明已处理、发布未核查、必要记录无效时拒绝。历史重要冲突采用保守校验；未扫描正文、目录和旧模块候选明确列为未覆盖。记录单文件上限 16 MiB，历史按 ID 读取，不承诺跨文件事务或跨进程锁。
- 验证：真实临时工作区覆盖取消、候选暂留、未覆盖确认、重要冲突、发布不确定、版本变化、响应丢失后的重试和交付后历史快照。
