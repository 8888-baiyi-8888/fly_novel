# 独立角色委派工具

## 问题

角色委派工具需要向角色子 Agent 传递角色 ID，并保持独立工具职责；角色资料检索由后续角色 Agent 优化实现。

## 决定

角色工具位于 src/tools，直接调用通用 SubAgent 服务，不依赖通用工具包。委派请求可携带创建参数；Provider 须显式声明支持，Spawn 可信创建方验证并复制参数后交给 Agent Factory。角色 ID 保存在子实例的 info.parameters，不伪装为已读取资料。

## 影响与验证

固定模型测试验证父 Agent 工具调用、不同 ID 的实例隔离、取消和释放；角色 ID 不自动进入模型消息，也不验证角色存在。无参数委派仍按原契约使用。
