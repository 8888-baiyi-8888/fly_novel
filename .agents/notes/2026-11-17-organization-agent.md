# 组织 Agent 装配与委派

组织内容和成员关系由专用 Agent 开发，主 Agent 负责协调。独立入口以可信世界配置绑定组织目录、初始化存储、工具及持久 Session；主 Agent 通过持久子 Agent 路由委派，目录服务按负责人建立独立绑定。取消或关闭时等待子运行和已受理操作，失败不删除已有资料。

地图和人物引用仅从可信应用显式提供的现有句柄解析；服务缺失时保留未关联线索，不重复打开已占用的地图存储。引用句柄由外部调用方管理，不随组织 Agent 关闭。角色授权管理及世界演化历史不在该入口实现。

固定替身验证实际工具写入、共享目录登记、委派与身份隔离、会话恢复、取消及资源释放；替身不证明真实模型会正确规划。
