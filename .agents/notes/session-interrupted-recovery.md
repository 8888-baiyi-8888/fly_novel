# Session 中断恢复和格式升级

问题：进程退出后可能留下未结束 Turn 或不完整 JSONL 尾部；没有持久化检查点时不能据缺失开始记录断言工具未执行。

决定：工具执行前刷新开始记录，恢复时参照官方补齐未配对结果及 interrupted Turn；旧会话没有检查点依据时一律保守标记工具结果未知。写入项目 JSONL v2，写打开 v1 时发布新版本并保留原文件；不完整尾部只读取完整前缀，写打开 v2 时截断未完成尾部。

影响：Session 文件格式不能与官方格式互读；Agent Loop 在模型请求前、工具执行前和 Turn 结束后检查持久化。目录级崩溃耐久性和同一会话并发写入不在当前范围。

验证：构建、真实文件迁移和中断恢复、检查点失败、持久化后端卸载及 Session、工具和 Loop 聚焦测试通过。
