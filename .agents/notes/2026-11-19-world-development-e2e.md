# 世界发展规划端到端验证

问题：插件与独立 Agent 测试不能单独证明主 Agent 能委派三个规划模块并核对实际关联。

决定：用两个隔离世界、真实局势及人物存储和固定模型替身走查主子 Agent、多个局势、三类规划及目录变化；同时提供可恢复的独立真实模型样例。

影响：固定替身只验证实际执行路径，真实模型样例也只覆盖指定输入；角色自主行动、故事执行与世界演化不在本阶段提供。按方案查询还需报告局势条目已缺失或无法读取，不能只核验方案本身。

验证：聚焦测试和真实模型样例的执行方式见 `docs/cookbook/world-development-agent-validation.md`。
