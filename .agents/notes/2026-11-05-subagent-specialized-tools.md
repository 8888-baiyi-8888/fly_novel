# 按子 Agent 类型封装委派工具

## 问题

不同类型的子 Agent 可能需要不同参数；直接让模型选择内部 Preset 并理解全部类型的参数会增加工具调用负担。

## 决定

按子 Agent 类型或委派能力封装专用工具，由父 Agent 按职责装配。各工具内部指定对应 Preset，复用通用 SubAgent 服务、Provider 与 Driver；工具不对应预创建的具体 Agent 实例。每次业务参数的传递、校验和消费仍需设计。

## 影响与验证

该决定写入第三阶段 Tool SubAgent 计划，当前不增加工具或改变运行时契约。后续验证不同工具参数、实际创建类型、错误处理与资源释放。
