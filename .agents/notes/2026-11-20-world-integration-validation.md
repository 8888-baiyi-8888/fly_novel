# 跨模块第一版整合验证

范围：双世界固定替身分别装配实际主子 Agent、业务存储、目录和 Session；修仙场景覆盖八类专用 Agent，城邦场景保留未委派的专有内容，并核对候选局势对应的发展方向。测试读取实际成果正文并保存待审总览，固定替身不证明真实模型的自主规划质量。

真实模型：隔离世界的主 Agent 委派地图和组织并保存总览，恢复同一会话读取成果的样例最终通过。首次地图子任务超过 8 分钟无结果；随后两次恢复分别在地图和组织任务期间达到测试取消阈值。核查已有文件后进一步缩小任务范围，恢复同一会话保存关联组织及总览；完成后的会话恢复未新增或覆盖总览。地图中出现两个可能超出样例近期范围的额外城镇，地图及组织正文还出现与结构化地点 ID 不一致的额外文本标识；总览已报告该问题。测试保留全部文件及会话，不自动删除或覆盖。简短模型请求可连通，但长任务等待原因未确定，不能归因于特定供应商、网络或文件系统缺陷。

影响：真实模型路径样例的成功依赖多次恢复及明确指出现有成果，不证明模型能稳定自主完成整合，也不证明生成内容已通过用户审阅。样例仅配置地图和组织，总览列出其他未配置范围；额外地点及文本标识需人工核查。系统级锁、跨文件原子快照及故事角色权限不在当前能力范围内。
