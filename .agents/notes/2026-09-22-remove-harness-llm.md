# 移除旧 Harness 与 LLM 运行层

## 问题

项目决定使用 LangChain Deep Agents，旧 Harness 目录规划和基于 Cordis 的 LLM 运行层需要移除。

## 决定

删除 src/harness、src/llm、旧模型调用入口与适配器注册表，移除 Cordis 依赖和手动模型测试命令。本次仅清理，不安装或接入新框架。

## 影响

模型调用入口及其测试一并移除；配置读取、凭据加解密、密钥初始化及其有效测试保留。本机配置、密文和密钥不变，历史决策记录保留。配置测试移除模型请求断言，继续验证固定路径、重复读取、无解密副作用和格式拒绝行为。

## 验证

清除旧构建产物后执行类型检查、构建及 config/app 测试；检查当前源码与文档无旧框架引用，并检查 Markdown 链接和变更空白。
