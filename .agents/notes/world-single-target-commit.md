# 地点和人物受控发布

影响检查跨多个独立存储，单次版本复核无法阻止复核后至写入前的同进程修改。世界协调器在模块自身队列和本机文件锁之前受理操作；可信发布装配必须覆盖世界资料和业务记录根，并拒绝未接入的文件后端。协调不代替单可信写入进程，也不提供跨文件事务。

确认、发布操作、当前正文和候选分开保存。候选在发布前条件升级到版本 2 的 `publishing` 并继续独占，正文已核实后转为 `committed`。发布前确定没有写入时可以条件恢复为版本 1 的活动候选；结果不确定时保留占用并要求可信应用展示实际版本、接收用户明确选择，选择保存到发布记录。人物使用现有初始化操作和索引恢复，但保留原确认状态并拒绝旧候选。

聚焦测试覆盖地点和人物发布、旧候选、不同步的确认和基线、取消、重复请求、发布前失败、写入后响应丢失、候选状态写入失败、人物索引恢复及后续资料变化；世界协调另测等待、嵌套、关闭与真实存储竞争。
