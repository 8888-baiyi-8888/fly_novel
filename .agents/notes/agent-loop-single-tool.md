# Agent Loop 单工具调用

问题：独立 Agent Loop 包需要访问每个 Agent 的工具服务，并将结果接入模型历史。

决定：Tools 成为独立工作区包；Loop 从当前 Context 获取可选服务，工具可见时要求调用方配置授权工作目录。每个模型响应只接受一次工具调用，将 assistant、调用和结果写入 Session 后进入下一 Step。

影响：无工具的 Agent 保持现有装配；工具错误作为模型可见结果进入下一次请求。多调用和最大 Step 保护留给后续步骤。

验证：固定适配器与真实 read_file 验证两次请求、Session 关联；聚焦测试覆盖未知工具、多调用拒绝和缺少授权目录。
