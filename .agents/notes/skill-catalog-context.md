# Skill 目录发布到模型上下文

## 问题

模型需要在加载正文前看到当前 Agent 获授权的 Skill 摘要，并在来源变化时避免使用旧目录。

## 决定

Skill 工具插件提供当前实例的 Step 上下文；Agent Loop 每次模型请求前查询并附加摘要到既有系统消息。发现失败时停止请求，空目录清除旧摘要；不改变 Session 事件或持久化格式。与官方独立持久化用户目录消息不同，本实现使用现有系统消息并按 Step 重建。

## 影响与验证

目录会进入现有系统消息事件并在恢复后重新查询。固定模型替身验证实例隔离、禁用模型调用、正文不提前发送、变更、空目录和发现失败重试。
