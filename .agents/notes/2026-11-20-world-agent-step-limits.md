# 世界初始化 Agent 步数与恢复

问题：世界初始化任务可能超过 Agent Loop 默认的每轮 10 步，应用入口缺少可信配置，子 Agent 达到上限后仍需保留成果并恢复会话。

决定：世界入口接受主 Agent 的 `mainMaxSteps`，各专用 Agent 接受 `maxSteps`；均在打开业务存储或创建 Session 前校验正整数，省略时沿用运行时默认值。达到上限沿原错误路径报告 `MAX_STEPS`，不自动重试或覆盖成果。

验证：主 Agent 在写入草稿后达到上限，恢复同一 Session 读取原文件；地图 Agent 在保存地图后达到上限，独立与委派路径均报告失败并可继续。固定模型替身不能证明真实模型一定会正确排查。
