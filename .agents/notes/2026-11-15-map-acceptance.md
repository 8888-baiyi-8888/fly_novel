# 地图端到端验证

- 问题：地图 Agent 需要验证双世界委派、真实工具和真实模型规划，而单独工具测试无法证明跨模块协作。
- 决定：增加两个固定样例的端到端测试和显式启用的真实模型检查；测试使用隔离世界，真实模型成果保留在临时目录供人工审阅。
- 验证：固定替身覆盖同名候选、地图读取、坐标、连通覆盖、目录登记和跨世界读取拒绝；补充目录不可用与未知提交结果。一次 DeepSeek 真实请求创建地图概览、两个有父子关系的地点及外海留白，并主动核对坐标；它没有装配目录工具，不能据此判断目录登记能力。
- 限制：真实模型曾将未创建的地点说成 `unexpanded`、将目录工具未提供说成目录不存在、将父画布坐标误报为世界坐标，及自行增加用户未要求的留白。补充提示后复测分别纠正，坐标工具同时增加 `targetCanvas`；最后一次真实复测通过留白和世界坐标断言。真实调用不能证明其他世界和任务的规划质量，业务仍须核对成果。
