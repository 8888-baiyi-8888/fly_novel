# 世界 Agent 身份与生命周期

问题：主 Agent 和独立角色 Agent 分属不同装配入口，原有角色入口的局部占用不能协调跨入口的同一世界身份。

决定：世界初始化业务层提供进程内身份占用；主 Agent 在创建前取得占用，角色 Agent 共用该占用，成功关闭后释放。创建回滚或释放失败导致资源状态不确定时保留占用。新世界入口要求可信应用声明同世界仅有一个写入进程。

影响：不同世界和身份不共享占用；调用方重建时负责提供相同目录及 Session 配置。单进程声明不是跨进程锁，旧的单工作区主 Agent 入口没有世界身份，不能纳入该身份占用。Session 恢复不等于长期记忆恢复。

验证：使用门闩覆盖启动期间身份竞争、跨入口冲突、不同世界、启动失败、重复释放和清理失败；结合持续子 Agent 的取消、迟到实例释放及 Session 恢复测试。
