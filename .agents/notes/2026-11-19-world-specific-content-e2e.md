# 世界专有内容端到端验证

问题：专有 Agent 需要依据既有世界资料自主选择主题，同时保证跨主题内容不重复和其他模块隔离。

决定：使用修仙与航海两个隔离世界、真实地图资料和固定模型替身走查主子 Agent、两主题共用内容、目录变化与来源版本；提供恢复同一 Session 的真实模型样例。

影响：固定替身只验证预设调用路径；真实模型结果需人工审阅，不证明真实主 Agent 的委派或所有世界的规划质量。规则语义冲突与角色视角隔离不由本模块自动完成。

验证：首次真实模型运行达到最大 Step 数，已保存两主题和两内容；核对实际文件后恢复同一 Session，模型完成报告且未新增重复文件。聚焦验证命令见 `docs/cookbook/world-specific-agent-validation.md`。
