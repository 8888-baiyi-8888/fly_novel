# 会话模块按子块组织目录

## 问题

按文件拆分职责后，消息视图、协议类型和边界校验仍全部平铺，顶层文件过多，相关实现缺少目录归属。

## 决定

将消息视图实现收拢到 surface/，会话协议类型收拢到 types/，历史导入及会话头校验收拢到 validation/。目录内文件去掉重复的职责前缀，使用明确的相对路径引用目录入口；同步更新全部源码引用。消息视图元数据校验仍归 surface/，与替换规则共同维护。顶层保留 Session、观察者通知、请求头折叠和公共入口。

## 影响

本次只改变文件位置和相对导入，不增加公共导出，不修改 Session 类原文，也不修复此前待讨论的问题。types/index.ts 接替原 types.ts 的事件映射声明位置；相关源码引用一起迁移。目录职责记入 AGENTS.md 与会话 README。

## 验证

对迁移前快照与迁移后文件逐一比较，全部 16 个源码文件除相对导入外原文一致，Session 类逐字符一致。继承根配置的会话模块聚焦类型检查通过，README 本地链接及 git diff --check 检查通过。
