# 世界资料目录格式与目标校验

问题：资料目录需要可持久读取的版本化格式，并防止模型路径越过可信 Agent 专属目录或重复引用同一成果。

决定：使用版本 1 JSON，严格校验字段、身份、路径、摘要和记录版本；显式初始化以独占创建保护已有文件。读取时对可解析的本人目标识别真实路径别名，缺失或不可访问的成果保留原记录。登记目标以可信世界配置和业务身份校验，真实目标必须位于所属目录。

影响：格式与路径校验独立于尚未实现的世界目录服务和模型工具；读取不修复损坏文件，不能防止本机恶意并发替换与硬链接。无法解析的成果别名在恢复访问前无法判断重复，应在后续服务操作中重新校验。

验证：聚焦测试覆盖格式往返、重复 JSON 字段、未知版本、初始化冲突、文件保留、缺失成果、重复链接目标以及跨目录和跨世界路径拒绝。
