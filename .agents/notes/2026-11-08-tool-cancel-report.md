# 取消后的工具部分结果

问题：多文件操作在取消时可能已有磁盘提交；ToolsService 原先统一覆盖工具返回值，导致已提交事实无法记录。

决定：工具可显式声明 `reportOnAbort`，保留取消后正常返回并通过输出校验的执行报告；其他工具仍返回 ABORTED，未开始的批次调用仍不执行。

影响：声明方负责准确区分已提交、未执行和未知结果；Loop 仍以取消结束 Turn，成功报告写入 Session 并可在后续请求中读取。异常或无效报告不当作成功。

验证：工具服务测试覆盖报告、后续调用取消和无效输出；真实 Loop 测试覆盖取消后报告进入 Session，同时保留普通取消行为。
