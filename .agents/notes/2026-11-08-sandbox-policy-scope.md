# Agent 文件修改策略作用域

问题：沙箱策略必须来自可信装配；根 Context 的策略不能被未授权的 Agent 继承，模型也不能通过工具参数扩大权限。

决定：引入独立策略服务，每个 Agent 显式装配固定且不可变的策略，默认只读；工作区写入要求显式的现有真实目录，附加根由可信配置提供。Agent Factory 总是隔离该服务。

影响：当前不提供上游 Session 模式投影和调用级提权；沙箱后端需依赖本 Agent 的服务并执行实际检查。上游平台临时根及路径检查后的竞争限制仍须在生产装配前评估。

验证：聚焦测试验证默认模式、无效配置、不同 Agent 配置隔离、根策略不继承和销毁后其他 Agent 不受影响。
