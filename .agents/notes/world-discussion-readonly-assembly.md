# 讨论入口的只读基础装配

问题：初始化主 Agent 的草稿写工具和专用 Agent 的业务写工具会直接修改当前资料。

决定：可信应用显式声明第一版完整后可选择只读讨论装配；专用 Agent 使用原有职责 Preset 和只读工具，不借用初始化存储，讨论 Session 与初始化 Session 分离。候选适配完成前不装配目录写工具。

影响：入口保持初始化模式原有行为；讨论模式仅能读取和搜索，尚不能形成候选。此限制是程序权限，不依赖提示词。

验证：固定模型替身装配真实工具，检查当前资料可读、主 Agent 和地图专用 Agent 的写工具不可调用且原文件不变；类型检查、测试编译及初始化工作区回归测试通过。
