# SubAgent 创建交接与回滚错误

## 问题

创建期间取消可能发生在 Agent 创建接口无法中断时。若创建方或 Driver 回滚失败，核心服务关闭需要能区分该失败与普通启动失败。

## 决定

创建交接等待创建方结算；取消后若创建方返回句柄，先等待释放再拒绝。未交付资源的回滚失败以 SubagentStartupCleanupError 同时保留启动原因和清理错误。核心服务关闭期间收到该错误时，向启动和关闭调用方均报告；普通启动失败只由启动调用方处理。

## 影响与验证

创建方必须在回滚失败时使用该错误类型，服务不会根据普通错误或信号猜测清理失败。模拟测试覆盖创建中取消、异步释放和服务关闭期间失败传播；真实 Manager 的生命周期交错仍需后续验证。
