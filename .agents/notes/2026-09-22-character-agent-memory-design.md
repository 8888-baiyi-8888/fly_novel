# 角色模板与个人记忆

## 问题

角色需要记住自身言语、行动和亲历事件，并在独立运行之间维持连续性。候选输出与实际发生事件混用会污染后续经历。

## 决定

在[角色 Agent 详细设计](../../docs/modules/agents/character-agent.md)定义显式记忆输入与可选受限查询，由业务侧在采用后记录实际内容。行动尝试与结果分开，状态变化作为建议；台词与动作通过有序表现列表保留时序。

## 影响

角色模板负责使用记忆，调用方负责版本绑定和采用，业务侧负责保存、去重和冲突检查。首版不要求模型可写长期记忆工具或向量数据库。公共设计通过链接关联细节。

## 验证

本次仅交付设计文档，检查相对链接、文本格式及公共契约一致性。运行时验收由详细设计列出，未实施或运行相关代码测试。
