# 文件修改沙箱后端

问题：本机文件后端的工作目录只负责解析，不能限制修改位置；策略服务本身也不执行文件访问。

决定：以显式装配的沙箱文件后端替代同作用域的本机后端，按 Agent 的固定策略重新解析并检查修改目标，移动检查两端。作用域释放等待已开始的修改并拒绝后续修改。策略不可从模型工具参数覆盖，读取继续交给独立授权机制。

影响：复用上游工作区、附加根及平台临时根语义；检查后到系统调用之间仍存在路径替换竞争，不能视为内核沙箱。生产 Agent 装配前须重新评估并补足读取、搜索及业务资料保护。

验证：真实 Harness 测试验证只读、工作区内和根外写入、缺少策略、重复后端及释放；其他修改、链接和并发场景按计划继续验证。
