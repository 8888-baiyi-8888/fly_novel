# 初始化恢复与交付验证记录

- 目标：验证可信入口的完整调用链，以及正文发布和交付记录写入后的进程退出。
- 结果：双世界固定模型样例覆盖第一版、讨论、影响检查、确认、发布、交付及重新打开；正文发布后和交付记录写入后分别执行子进程退出并核查恢复。相关回归 19 项通过，类型检查、正式构建、构建产物装配冒烟和本地文档链接检查通过。
- 真实模型：在已授权的 DeepSeek 端点和隔离合成资料上，模型创建城门候选，测试模拟用户确认后完成受控发布与交付；程序断言通过，输出为“曲水城城门夜间关闭。”，实际用户确认和更广泛语义质量不在该样例内。
- 限制：记录按 ID 查阅；未覆盖世界正文、目录、旧模块候选和人物索引的范围须明示。以上中断点不证明跨进程锁、跨文件事务或断电持久性，后续世界演化未接入。
