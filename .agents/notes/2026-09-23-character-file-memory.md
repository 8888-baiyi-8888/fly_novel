# CharacterAgent 接入 Deep Agents 文件记忆

日期：2026-09-23

问题：内存检查点只能延续单实例会话，角色需要跨实例、跨重启保存知识，同时避免自建通用记忆系统。

决定：使用 Deep Agents memory 配置、FilesystemBackend 虚拟目录及内置读写工具。应用注册绝对 memoryRoot；角色按小说、分支、角色标识的 JSON 数组哈希定位 v1 目录，默认分支为 main。初始化独占创建空 AGENTS.md，不覆盖已有文件。摘要由 SDK 在新会话加载，详细文件按需读取；当前 SDK 缓存同会话摘要，必要时通过 read_file 读取更新。

边界：磁盘笔记属于模型记忆，不是正式剧情提交，写入由模型工具调用决定。失败或取消不回滚已写文件。会话检查点仍在内存中；同身份新实例共享文件但不共享会话。进程内按真实目录拒绝并发运行，finally 释放占用；多进程写入需应用串行调度。存储根是可信应用配置，虚拟路径后端不替代操作系统沙箱，目录中不得布置跨数据范围符号链接。

格式：v1 为布局版本，Markdown 作为文本读取，不解析为结构化角色状态。后续格式改变需显式迁移，不自动读取其他版本或清除历史数据。

验证：11 项 CharacterAgent 聚焦测试通过，包含真实 SDK 工具落盘、新实例摘要加载和详情读取、小说分支角色隔离、越界拒绝、初始化失败、同目录并发及失败后释放。使用模型替身与临时目录，无真实供应商调用。
