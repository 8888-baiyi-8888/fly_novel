# 世界初始化跨模块整合计划

问题：十个内容模块及其专用 Agent 已分别建立，但配置项存在和单模块测试不能证明多模块共享读取、生命周期及完整第一版交付已经贯通。

决定：以两个不同世界为场景，先核对可信句柄所有权及进程内占用，再逐步验证多 Agent 协作、待审总览、失败保留和同一 Session 继续；不强制每个世界生成全部模块。

影响：跨模块整合只交付供用户整体审阅的第一版，不提前实现局部讨论、确认提交、世界运行或长期记忆；具体共享方式以真实代码和聚焦验证为依据。

验证：对照世界入口、目录、Session、各模块说明、已有生命周期测试及 Agent Loop 默认步数，检查计划与阶段边界。
