# 世界初始化样例续跑

- 问题：样例每次创建新世界，取消后无法复用任务、会话和已保存的资料；仅恢复会话不能证明业务完成或写入是否成功。
- 决定：由调用方指定原样例目录，严格核对任务、世界、目录及 Session；优先复用已有业务记录和已完成发布，无法判断的情况停止核查。第一版阶段对已有文件或旧会话的专用模块关闭写入委派，人物索引经校验为空时允许复用原 Session 继续。
- 影响：不迁移或删除已有数据，不重新创建已有世界；未知版本、损坏的 Session 尾行、已有总览但缺少第一版判断、结果不确定的发布或交付均拒绝自动推进。进程内协调仍不提供跨进程锁，调用方须先停止原进程。
- 验证：固定模型覆盖第一版中断及人物空索引、跨进程续跑、候选与确认复用、发布成功后响应丢失、重复读取已完成交付、未决发布、交付结果不确定和残缺 Session 尾行。对原用户目录的只读核查前后比对了全部 41 个文件的内容摘要，未发生变化。
