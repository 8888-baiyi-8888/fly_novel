# 编辑器与构建使用独立 TypeScript 配置

## 问题

根配置排除了模块测试，编辑器未将这些文件归入包含 Node 类型的项目，而命令行使用显式测试配置，导致两者诊断不一致。

## 决定

根 tsconfig.json 覆盖源码和测试，启用 noEmit，作为编辑器和类型检查入口。新增 tsconfig.build.json，显式开启输出并排除测试。测试配置继承根配置，显式开启输出到 .test-dist。

## 影响与验证

构建和类型检查脚本同步指向对应配置，测试命令保持不变。检查根配置包含手动测试、构建配置排除测试；执行类型检查、正式构建和自动化测试，确认正式产物不含测试。
