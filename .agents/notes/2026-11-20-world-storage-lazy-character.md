# 世界资料中的人物按需读取

问题：世界入口为历史、局势和其他 Agent 装配人物引用时提前打开人物存储，人物索引尚不存在会阻塞不读取人物的其他任务。

决定：共享人物和关系提供只读能力对象，在实际查询时获取存储。人物插件单独暴露只读工具，引用校验继续核对世界及负责人目录；实际打开和读取失败向调用方报告，不转换为空资料。

影响：不改变持久化格式、人物初始化规则和单写入进程约束。未使用人物资料的任务不创建人物索引；角色创建仍由所属 Agent 执行。

验证：真实工作区测试覆盖历史、局势、发展规划和专有内容在人物目录未初始化时运行，以及实际查询的拒绝路径；人物工具及跨模块引用测试覆盖已有行为。
