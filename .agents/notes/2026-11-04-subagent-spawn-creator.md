# Spawn 子 Agent 的可信创建装配

## 问题

Spawn Provider 需要根据委派请求选择现有 Preset，并通过同一框架创建独立实例及释放资源。

## 决定

Agent 包提供可信创建函数，应用以 Preset ID 提供可委派的插件配置；使用同一框架的注册表与 Manager，标准 Loop 显式配置模型并拒绝持久化 Session ID。创建方生成独立运行与 Agent 标识，创建成功后句柄通过同一 Manager 释放。自定义插件的会话隔离由可信应用确认。

## 影响与验证

实际 Spawn 使用角色和导演 Preset，固定模型测试验证提示词、父历史隔离、不同 Session、失败回滚与释放。取消和关闭竞争由下一步覆盖，不声称已完成真实模型验证。
