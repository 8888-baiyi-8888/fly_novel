# 工具执行上下文与 Agent 作用域

问题：同一工具定义在不同 Agent 中执行时需要调用身份和各自的授权目录。

决定：Harness 在每个 Agent 的隔离 Context 提供身份快照；Tools 插件声明该服务依赖。ToolsService 从实际工具调用生成 callId、name 和信号，并使用所属服务的 Agent 身份。

影响：工具可区分 Agent 和调用；独立服务可以不绑定 Agent。工具注册和可见性按实例隔离，工作目录仍由可信调用方提供，不以 Agent 身份代替授权。

验证：固定模型驱动两个 Agent 使用同一工具读取各自目录，检查身份、调用 ID、取消信号以及跨目录访问被拒绝。
