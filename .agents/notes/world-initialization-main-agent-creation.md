# 世界初始化主 Agent 的创建

## 问题

世界初始化主 Agent 需要使用现有 Harness、专有提示词和 Skill 服务，同时保持可信来源配置和实例隔离。

## 决定

新增主 Agent 专有角色和内置 Preset，通过现有 Manager 创建、运行和销毁。Skill 工具保持在具体工具目录，并以独立工作区包供 Harness 注册。应用提供模型路由、适配器、授权工作目录和 Skill 来源；不自动依赖源码目录或引入确认与规划业务。

## 影响与验证

主 Agent 的创建配置需要显式提供 Skill 根目录。固定模型测试覆盖插件装配、调用、初始化失败、模型失败和实例隔离；干净构建后通过包入口验证创建、目录展示和运行。
