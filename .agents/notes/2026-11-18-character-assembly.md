# 人物关系与跨模块装配

角色创建 Agent 在其专属角色根内使用 `relationships/`，由应用打开并持有人物及关系存储，按初始化阶段装配版本更新和关系工具；已有角色资料、索引及候选格式保持不变。人物解析使用同一角色存储，目录和世界不由模型指定。插件作用域关闭后依次关闭关系和人物存储。

地图和组织查询可使用可信调用方提供的已打开句柄；世界配置核验世界、负责人和目录，工具使用规划者只读绑定，句柄由调用方负责生命周期。此路径不提供故事角色的知识隔离，不自动共享专用 Agent 自己打开的句柄。

验证覆盖独立及委派创建、双端关系查询、初始化版本更新、引用绑定拒绝、会话恢复及已有模块回归。固定模型替身只验证执行路径。
