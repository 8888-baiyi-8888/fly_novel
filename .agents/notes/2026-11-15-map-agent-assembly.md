# 地图 Agent 与委派装配

- 问题：地图工具需要专用 Agent、可信世界与目录绑定，并与现有角色和基础信息委派共存。
- 决定：新增地图 Agent Preset、职责提示词与独立应用入口；地图插件负责注册和注销地图工具，可信应用持有地图存储与文件后端。主 Agent 通过持久 Provider 和地图插件中的 `delegate_map` 委派。
- 影响：地图根取自世界中地图负责人目录，目录结构须预先存在；Session 由可信配置绑定。可选目录服务由独立入口持有或由主入口共享，父运行结束时等待子运行释放。未改变地图持久化格式。
- 验证：固定模型替身结合真实文件和目录工具验证独立运行、三种委派共存、身份隔离、目录登记、Session 恢复、配置失败和取消清理；不代表真实模型的规划质量。
