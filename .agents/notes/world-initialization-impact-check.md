# 只读影响线索检查

问题：候选保存和现有查询不构成可追溯的影响报告，也不能区分已检查、读取失败和未覆盖。

决定：可信应用绑定世界、讨论、目标与模块存储，保存独立版本 1 检查报告；地点扫描直接地图关联及已关联历史，人物扫描组织成员及已关联历史。范围版本可重查，未关联线索和其他范围单列，不把关联直接当成语义冲突。

影响：检查只写独立报告，不改当前资料或候选；报告可被篡改检测和按范围重查，但不提供跨文件锁、用户确认或提交。报告目录与讨论、世界和 Session 根隔离，调用者持有服务与后端。

验证：真实模块数据测试覆盖范围新增、分页失败的已完成来源、候选并发变化、取消、读取失败和未知报告版本；应用工具测试覆盖授权目标及拒绝绕过。未覆盖的影响不因结果为空而被判定不存在。
