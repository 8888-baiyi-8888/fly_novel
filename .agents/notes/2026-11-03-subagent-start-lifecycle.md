# SubAgent 启动与服务关闭

## 问题

Provider 启动可能与服务关闭或请求取消交错；Provider 发布后返回的句柄不能无人负责，已交付的运行又由调用方持有。

## 决定

服务只跟踪未交付的启动，关闭时取消并等待它们。取消后迟到的句柄由服务处理结果拒绝并释放，清理失败向启动和关闭调用方报告。已交付的句柄由调用方释放，服务关闭不取消它。Provider 负责在父 Agent 范围内分配唯一运行标识，服务不登记已交付运行或检查标识冲突。

## 影响与验证

Provider 必须在启动取消时结算并回滚，否则服务关闭会等待。模拟 Provider 测试覆盖关闭交错、迟到句柄、清理失败、取消与并发；真实 Provider 和 Cordis 插件需在后续步骤验证。
