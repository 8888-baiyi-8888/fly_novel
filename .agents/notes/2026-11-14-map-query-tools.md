# 地图查询与工具归属

- 问题：地图地点可有多个父级，查询需要保留父级路径、实际矩形片段和一致的分页结果；模型不能选择世界或授权目录。
- 决定：在 `@fly-novel/map` 内提供查询和模型工具定义，调用方绑定受控存储及 Agent 身份。每次查询重建并验证文档视图，版本绑定内容和筛选条件；多路径画布冲突拒绝，空间搜索使用实际范围。
- 影响：地图数据不改变格式；查询扫描全部地图文档并受数量限制，不提供跨进程原子快照。工具由可信调用方注册，地图 Agent、目录登记及主 Agent 委派另行装配。
- 验证：使用本机文件后端测试多父级、逐级换算、世界比例、分离矩形及边缘接触、单向连通、分页冲突和工具身份权限。
