# 文件搜索读取边界

问题：上游搜索通过本机 ripgrep 访问文件，工作目录不是读取权限边界，搜索结果可能包含模型无权访问的路径或内容。

决定：复用文件工具的可信读取根，执行前解析并检查目标，搜索输出在返回前逐项解析和检查路径；固定使用打包 ripgrep、无 Shell 参数数组及 --no-config。原始结果设内存上限，不保存未经授权的溢出文件。

影响：目录和文件在检查后仍可能被外部进程替换；路径检查不是内核沙箱，不能保护恶意本地并发和硬链接。生产装配时须评估可信工作区与资料保护。

验证：固定本机二进制的搜索、无结果、越界和原始输出溢出由聚焦测试验证；结果过滤及真实模型执行链由后续步骤验证。
