# Skill 来源按 Agent 实例装配

## 问题

Skill 加载工具需要使用与 Agent 查询目录相同的来源，并避免继承根 Context 的来源和工具注册。

## 决定

可信调用方为实例配置文件系统来源；Skill 工具插件依赖当前作用域的 Skill 和工具服务。Agent Factory 为 Skill 和工具服务建立隔离范围，作用域销毁时注销工具和来源并关闭服务。暂不实现目录发布或子 Agent 权限继承。

## 影响与验证

应用需显式注册 Skill 工具插件并在 Preset 中装配相关服务。使用多个实例与不同来源验证同名 Skill、猜测名称、目录授权和销毁隔离。
