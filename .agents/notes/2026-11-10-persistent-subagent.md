# 持续子 Agent Provider

- 问题：部分子 Agent 需要在多次委派间恢复自己的会话，普通 Spawn 创建器保持独立临时会话。
- 决定：新增与 Spawn 和 Fork 并列的 `persistent` Provider，复用运行驱动；可信应用绑定 Preset 和创建函数，负责身份、Session 和其他资源。
- 影响：同一个创建函数在启动至释放期间独占；恢复方式由可信应用确定，不继承父会话，也不提供跨进程互斥或长期记忆。
- 应用：世界初始化入口将角色创建配置绑定到该 Provider，专用工具只传任务；普通只读委派继续使用 Spawn。
- 验证：覆盖连续委派、身份忙、启动取消、清理失败及角色创建 Agent 的实际 JSONL 会话恢复。
