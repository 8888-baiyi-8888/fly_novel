# 影响检查与发布集成验证

固定模型替身与真实临时工作区验证两个世界的候选隔离、模型伪造确认、重要冲突、显式选择、默认建议、范围变化和取消；逐项发布测试补充部分成功、目录失败和恢复。子进程在正文发布后退出的测试重新装配存储并核查实际版本，未覆盖断电、跨进程并发写入或系统级隔离。

受限环境请求失败后，用户明确授权向 DeepSeek 发送隔离合成样例，两次真实模型测试通过；确认动作由测试代码模拟，未进行人工语义审阅。DeepSeek Harness 固定版本对照、实际验证范围和第 9 阶段边界见[验证与交接](../../docs/workflows/word-initialization/world-initialization-stage-8-handoff.md)。
