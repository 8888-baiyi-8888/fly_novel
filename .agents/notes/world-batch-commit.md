# 多目标受控发布

可信应用在世界协调范围内复核整组确认和候选，再按用户选择顺序逐项发布。批次采用独立的严格版本 1 JSON；单项目标的阶段、正文摘要、候选占用和目录核查分别记录。每次写入重新执行所属模块的版本、图和引用校验，保留当前确认状态，拒绝旧候选及不支持的新目标。

批次失败时停止后续目标，保留已发生的结果。中断时先停止批次，再逐项核查；不确定结果需要用户根据当前版本明确选择，未开始及失败目标须重新检查并确认。目录与正文不属于同一事务，目录过期或损坏独立报告，不自动生成简介或声称回滚正文。

聚焦测试覆盖地点先成功、人物失败、文件未开始、重新确认、记录写入响应丢失、目录故障和恢复，以及组织、成员、关系、历史、局势、规划、专有内容和文件的条件发布。
