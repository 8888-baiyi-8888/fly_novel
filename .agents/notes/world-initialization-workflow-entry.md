# 初始化可信应用入口

- 问题：任务、Session、讨论、审阅和恢复服务需要绑定同一世界，不能用 Session 或模型输出代替第一版判断或用户确认。
- 决定：新增可信 Node.js 装配入口和交互 API，复用现有服务及只读讨论 Agent；第一版依据失效时拒绝开启讨论。主 Session 的业务 ID 与后端 ID 使用同一派生函数。
- 影响：调用方提供已有目录、模块存储、模型及全部 Session 根并持有用户交互；入口负责自身创建的服务、Agent 和协调器，借用资源由调用方释放，不新增图形界面。
- 验证：真实临时工作区覆盖启动失败清理、重开、Session 只读恢复、固定模型讨论及写工具拒绝；正式构建和构建产物模块加载通过。
