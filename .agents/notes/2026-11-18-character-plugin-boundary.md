# 人物与关系插件归属

人物资料和人物关系由同一独立工作区包维护，格式、存储和工具集中在 `@fly-novel/character`；可信应用仍可独立使用存储。专用 Agent 委派保留在 `src/tools/subagent-character/`。角色创建入口通过 Cordis 插件作用域注册既有工具，释放作用域注销工具；存储生命周期属于应用。

目录和包入口调整不改变版本 1 角色 Markdown、关系 JSON、索引、待审及恢复记录，也不更换直接文件后端。初始化修改工具及关系工具由可信应用显式启用，角色创建入口不自动增加这些工具或角色授权。

验证覆盖包构建、插件注册与注销、现有主子 Agent、组织引用、角色和关系存储及失败恢复。
