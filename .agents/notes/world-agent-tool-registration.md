# 世界初始化主 Agent 的工具注册

## 问题

世界初始化主 Agent 需要读取工作目录内的文件，包括 Skill 引用的资源。单个工具注册失败不能阻止 Agent 创建。

## 决定

应用层创建函数按工具列表逐项注册 read_file 等工具，单项注册失败记录错误并继续。skill 由插件注册，失败时记录错误且不发布 Skill 目录。所有工具注册失败时仍返回 Agent。

## 影响与验证

read_file 的授权范围是主 Agent 的工作目录，即创建时的当前目录。固定模型测试检查单项和全部工具注册失败、日志、模型声明和继续运行；正常读取及路径边界使用文件工具测试验证。
