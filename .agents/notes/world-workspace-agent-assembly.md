# 世界工作区 Agent 装配

问题：世界配置已能描述多个 Agent 的目录，但原主 Agent 入口无法从稳定身份绑定角色资料目录，角色 Agent 也没有共享搜索工具。

决定：可信应用提供完整世界集合，新入口校验并选取世界，将主 Agent 和角色 Agent 的目录分别绑定到对应身份；角色 Session 根与所有传入世界读取根分离。角色 Agent 使用只读文件后端与搜索工具，角色资料仍由专用服务写入。

影响：主 Agent 文件修改受既有草稿后端限制，角色服务的根不与其他专属根、确认根或目录保护根重叠。文件观察只覆盖通过观察插件的工具，角色资料服务及原有 `read_file` 使用自己的直接访问路径。当前不提供统一身份互斥、其他特殊 Agent 的生产装配或跨进程锁。

验证：双世界配置下使用真实主 Agent、角色 Agent 及测试用第二个特殊 Agent，检查共享读取和搜索、越权拒绝及角色资料写入；运行角色持续委派和取消回归测试。
