# 多文件补丁结果和授权

问题：补丁可依次修改多个文件，预检读取可能访问授权范围外的数据，提交后取消或监听器失败可能丢失已完成修改的信息。

决定：复用上游规划、预检和顺序提交；每个预检目标先经过可信读取根检查，修改由沙箱后端独立授权。执行后报告每项完成、失败、未知或跳过及已修改路径，不回滚已完成操作；提交后监听器失败仍保留已知修改。

影响：补丁不提供跨文件事务；取消后依靠 ToolsService 的 reportOnAbort 保留报告。所有目标包括新增目标须在读取根内，调用级沙箱模式升级及图片能力未接入。

验证：真实工具链测试覆盖预检拒绝、创建／更新／删除、移动部分成功、失败、取消、观察监听器错误和同目标顺序操作。
