# 玄幻世界初始化规划

当用户希望创作玄幻世界或玄幻小说，并已确认对其构想的理解时，使用本 Skill 规划世界初始化任务。用户的要求和已确认的理解是规划依据；如果影响规划的关键意图仍不明确，先与用户澄清，不把猜测当成用户要求。

## 确定规划重点

从用户的构想出发，判断世界最有特色或对后续故事演化最重要的内容，说明为什么需要规划、需要达到什么深度。玄幻世界可能涉及修炼体系、超自然力量、特殊资源、不同种族或特殊空间，但这些只是观察方向，不是每个世界都必须包含的固定栏目。用户没有提出的设定可以由你在世界方案中主动构思，不应在理解用户意图时冒充用户原话。

世界应具备自身的规则、参与者和发展，能够为多部小说提供素材。一部小说可以包含多个故事；世界的运转不必围绕单一主角。区分世界事实、角色认知和小说最终呈现的内容。

## 组织规划任务

围绕识别出的重点组织任务，说明每项任务要解决的问题、预计产出、详略和需要依赖的其他结果。任务可以根据构想增加或调整，不必为每类设定创建固定 Agent 或固定流程节点。

- **世界性质与规则**：确定影响世界运转和故事推演的基本规则。若用户构想需要修炼或其他超自然能力，规划其来源、作用、限制及其对社会和角色的影响；不要为了填满模板强加境界或能力体系。
- **世界推进与第一个故事**：规划可能影响世界或多个重要地区的重大故事线，以及有意义的其他故事线；确定第一个要演化故事的起点、参与者、目标和矛盾。世界初始状态与该故事的起点保持一致。
- **地区与空间**：结合重要角色所在位置、合理活动范围及故事涉及的地点，确定需要重点规划的地区和周边。规划大致坐标、尺度、环境、层次和重要通行关系；区分地理、行政与势力范围，其他地区可以粗略处理。
- **主要势力**：先规划与初始局势、重要角色和故事密切相关的主要势力，说明其目标、利益、活动范围和相互关系；内部细节随实际需要和后续演化完善。
- **重要角色及成长**：按角色参与的故事范围及其对世界和其他角色的影响判断重要性，不只依据主角身份。第一梯队以约十人以内为参考，并非严格上限；对重要角色规划身份、经历、性格、目标、关系和可能的成长线。成长与其经历的故事相联系，但不预设所有遭遇、选择和结局。
- **历史与当前状态**：规划支持理解初始世界的广为人知的历史及其对当前局势的影响，考虑事件的时间、参与者和先后关系。隐藏历史可以留待后续补充；传闻、角色认知与已发生事实不能混同。

上述方向按世界构想选择和调整，不要求全部同等详细。对尚未确定或暂时不需要的内容，可以不写；后续演化需要时再补充。

## 安排依赖与协作

先识别各任务之间需要共享的信息，再安排可先开展、需要等其他结果或需要互相协调的任务。例如，地区的细化需要参考重要角色和故事的活动范围；角色与势力的规划也可能促使你调整故事起点。允许在整合时回看和修正规划，不将这些关系变成只能单向执行的固定步骤。

根据任务实际需要决定自行处理或委派；若当前没有可用的子 Agent 或资料工具，不声称已经调用。委派时应明确任务目标、所需上下文和预期结果，再将结果整合到同一世界方案中。

## 提交规划与整合方案

向用户或调用方说明：你识别出的规划重点、各任务的目标和预期成果、详略与依赖关系，以及准备如何整合成完整的第一版方案。规划要有足够信息供执行和审阅，不只罗列栏目，也不要求用户替你完成主要构思。

整合结果时，检查规则、历史、地区、势力、角色和故事之间已发现的矛盾；说明尚无法判断的影响，不把未发现冲突说成不存在冲突。对未来重大变化和角色成长提出方向，但具体事件、选择和结果由后续演化产生。
