# @fly-novel/initial-situation

初始局势格式与初始化受控文件存储。业务背景及后续 Agent、查询工具规划见[详细计划](../../../../docs/workflows/word-initialization/world-initialization-stage-6a-initial-situation-plan.md)，文件约定见[资料契约](../../../../docs/workflows/word-initialization/world-initialization-stage-6a-initial-situation-contract.md)。

`SituationStore.open` 接受可信世界、现有真实负责人目录、文件后端、访问模式、初始化阶段及单可信写入进程声明；`overviews/`、`situations/` 和 `candidates/` 必须已存在。调用方负责保持后端与引用解析器有效并等待 `close()`；身份占用限于当前进程，不是跨进程锁或系统级隔离。已关联引用须由可信解析器验证，同一方案内条目关联验证目标存在。目录登记、跨模块事务、确认提交和世界演化留存不由存储提供。

首次独占创建世界起点，随后创建不同待审总览及其条目。初始化起点说明可按读取版本更新；调用方须先核查已有相对时间资料，存储不自动换算历史。未确认文件按版本更新，已确认文件可建立独占模块候选；模块候选不直接提供提交。发生结果不确定时须检查返回路径，不能盲目重复创建。完整文档不能直接作为角色认知，角色可见性需由后续运行装配保护。

局势候选校验检查已有总览或条目的身份、归属和引用，不写入正文；世界起点候选不自动检查历史时间影响。

可信应用可调用 `publishReviewed` 按版本发布已审阅总览或局势，保留原确认状态并检查归属、引用和旧候选；用户授权和跨模块协调由[世界初始化发布服务](../../../world-init/README.md)负责。该入口不供模型工具直接调用。

`situationToolsPlugin` 将查询和写入工具注册到可信 Agent 身份及插件作用域；只读绑定不提供写工具。方案局势搜索扫描已记录文件，分页版本绑定数据与条件；关联查询保持记录方向，一致性检查仅覆盖方案及条目关联，并报告未检查范围。引用核验区分未配置、未找到、版本未知、未变化和已变化；解析错误继续报告，跨世界或身份不匹配拒绝。读取多个模块不形成原子快照，也不判断语义冲突或角色认知。
