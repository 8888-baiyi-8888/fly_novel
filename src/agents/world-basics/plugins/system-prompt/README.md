# @fly-novel/world-basics-system-prompt

世界基础信息 Agent 的 Cordis 提示词插件，依赖 `systemPrompt` 服务，随作用域注册和注销提示词。插件指导区分资料来源、建议、留白及成果状态，并在目录工具可用时指导更新本人简介；不提供文件工具、授权、持久化或用户确认能力。

在仓库根目录执行：

```bash
pnpm --filter @fly-novel/world-basics-system-prompt typecheck
pnpm --filter @fly-novel/world-basics-system-prompt build
```
