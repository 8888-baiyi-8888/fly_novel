# src/tools 目录说明

## 仓库结构

- `README.md`：目录职责和使用说明。
- `catalog/`：世界工作区资料目录专用工具实现。
- `filesystem/`：文件系统相关工具。
- `index.ts`：模块入口和导出。
- `skill/`：Skill 加载工具及其文件系统提供方。
- `subagent-character/`：角色专用工具实现。
- `subagent-history/`：历史 Agent 的专用委派工具。
- `subagent-initial-situation/`：初始局势 Agent 的专用委派工具。
- `subagent-organization/`：组织 Agent 的专用委派工具。
- `subagent-world-basics/`：世界基础信息 Agent 的专用委派工具。
- `subagent-world-development/`：世界发展规划 Agent 的专用委派工具。
- `subagent-world-specific/`：世界专有内容 Agent 的专用委派工具。
- `tests/`：所属模块的自动化测试。
