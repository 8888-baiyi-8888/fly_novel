# 故事级工作流业务模块

当前模块管理单轮初步事件规划：调用方提供任务、已知事实和发展方向，导演返回事件初步安排或无可推进事件及原因。程序生成独立运行 ID 与事件 ID；计划不代表事件已发生，也不更新世界状态。导演和模型由[应用入口](../app/story-planning.ts)装配。

`PlanStore` 在可信应用选择的现有真实目录中，以运行 UUID 为文件名独占创建版本 1 JSON，保存输入和规划结果。调用方必须提供全部需要隔离的业务根和 Session 根；记录目录不得与它们重叠。未知版本、重复键、损坏、无效身份和不符合格式的记录拒绝读取并保留原文件；不自动迁移其他格式。创建失败或结果不明时报告运行 ID，调用方须核查原文件，不盲目重试或覆盖。单个文件只创建不更新，不承诺跨文件事务、跨进程锁或断电持久性；路径检查不能防止恶意并发替换及硬链接。

本模块不执行故事、父子导演委派、角色互动或真实世界状态更新；这些能力属于[后续开发步骤](../../docs/workflows/story-workflow/story-workflow-stage-2-director-delegation-plan.md)。
