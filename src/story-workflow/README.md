# 故事级工作流业务模块

当前模块管理单轮初步事件规划：调用方提供任务、已知事实和发展方向，导演返回事件初步安排或无可推进事件及原因。程序生成独立运行 ID 与事件 ID；计划不代表事件已发生，也不更新世界状态。导演和模型由[应用入口](../app/story-workflow.ts)装配。

`PlanStore` 在可信应用选择的现有真实目录中，以运行 UUID 为文件名独占创建版本 1 JSON，保存输入和规划结果。调用方必须提供全部需要隔离的业务根和 Session 根；记录目录不得与它们重叠。未知版本、重复键、损坏、无效身份和不符合格式的记录拒绝读取并保留原文件；不自动迁移其他格式。创建失败或结果不明时报告运行 ID，调用方须核查原文件，不盲目重试或覆盖。单个文件只创建不更新，不承诺跨文件事务、跨进程锁或断电持久性；路径检查不能防止恶意并发替换及硬链接。

`CollaborationStore` 在与规划根隔离的可信目录中，按规划 ID 和事件 ID 保存独占尝试记录、模拟经过和最终协作结果，格式均为版本 1。一次协作仅处理一个初步事件：程序创建父故事与协作身份，并将所选事件作为子故事；最终记录保留所用完整规划、父导演任务、子导演安排、明确标记的模拟经过、子导演回报和父导演接收结果。重新读取时核对尝试、经过和结果的身份及内容；未知版本、损坏或不一致拒绝读取并保留原文件。

调用导演或模拟器前先独占创建尝试记录；同一规划的同一事件已有尝试时拒绝再次执行。模拟经过在回报前单独保存；失败、取消或结果不明时保留已有记录，调用方可读取模拟经过并核查，但不能自动重试。完成结果与尝试和经过是多个文件，不声称跨文件原子、跨进程锁或断电持久性；删除占用、重新尝试及完整恢复不属于本阶段。调用方保证记录根与世界、Session 和其他业务根隔离。

当前协作使用可信调用方提供的模拟器，不执行真实角色互动或更新真实世界状态。兄弟故事、多层拆分和提前汇报属于[后续开发步骤](../../docs/workflows/story-workflow/story-workflow-stage-2-director-delegation-plan.md)。
